# 마음결 — 마음을 그리는 쉼터

초·중·고 학생과 성인(교사 포함)을 위한 **미술심리치료 · 마음건강 선별검사 · 채팅 상담 · 위기 조기 발견** 웹 플랫폼입니다.
게임·스마트폰·AI·도박 의존, 고립감·무력감으로 힘든 사람이 스스로를 돌보고 세상 밖으로 나올 수 있도록 돕고,
위기 신호를 조기에 발견해 자살을 예방하는 것을 목표로 합니다.

## GitHub에서 바로 실행하기 (Codespaces)
[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/BunnyeoLee/maum?quickstart=1)

1. 위 버튼을 누르거나, 저장소 화면에서 **Code → Codespaces → Create codespace on main** 을 누르세요.
2. 1~2분 기다리면 설치와 데모 데이터 생성이 끝나고 서버가 자동으로 켜집니다.
3. 브라우저 새 탭으로 마음결이 열립니다. (팝업이 차단되면 아래 **포트(PORTS)** 탭의 3000번 주소 옆 🌐 아이콘을 누르세요. 편집기 안의 '간단한 브라우저' 미리보기는 연결이 잘 안 될 수 있어요.)
4. 다른 사람(학생·상담사)도 접속하게 하려면 포트 탭에서 3000번을 우클릭 → **Port Visibility → Public** 으로 바꾸고 주소를 공유하세요.

> Codespaces는 무료 계정 기준 월 120 코어시간(2코어로 약 60시간)까지 무료입니다. 사용하지 않을 땐 Codespace를 **중지(Stop)** 하세요.
> Codespaces는 시연·수업·시범 운영용입니다. 실제 운영은 아래 '운영 전 꼭 확인하세요'를 참고해 상시 서버(Render, 학교 서버 등)에 올리세요.

## 무료 서버에 올려 고정 주소로 운영하기 (Render + Turso + Brevo)
GitHub 저장소를 무료 서버에 연결하면 `https://maum.onrender.com` 같은 **고정 주소**가 생기고, GitHub에 코드를 올릴 때마다 자동으로 다시 배포됩니다. 모두 무료이며 신용카드가 필요 없습니다.

| 서비스 | 역할 | 무료 한도 |
|---|---|---|
| Render | 웹 서버 | 무료 웹 서비스 (15분 동안 방문이 없으면 잠들고, 다음 접속 때 깨어나는 데 1분쯤 걸림) |
| Turso | 데이터베이스 (가입·검사·상담 기록 저장) | DB 100개, 5GB |
| Brevo | 인증번호·결과 메일 발송 | 하루 300통 |
| GitHub Models | AI 상담사 (선택) | 무료 |

### 1단계. Turso — 데이터베이스 만들기 (약 3분)
1. https://turso.tech 접속 → **Sign up** → GitHub 계정으로 가입
2. **Create Database** → 이름 `maum`, 지역은 **Tokyo**(또는 가장 가까운 곳) 선택 → 만들기
3. 만든 데이터베이스를 열고 **Database URL**(`libsql://maum-...turso.io`)을 복사해 둡니다.
4. **Create Token**(또는 Generate Token) → 만료 **Never** → 나온 토큰을 복사해 둡니다. (한 번만 보여요)

### 2단계. Brevo — 메일 발송 준비 (약 5분)
1. https://www.brevo.com 가입 (무료 플랜)
2. 오른쪽 위 메뉴 → **Senders, domains & dedicated IPs → Senders → Add a sender** → 보내는 사람 이름 `마음결`, 메일은 본인 메일 → 그 메일함으로 온 인증 메일에서 확인
3. 오른쪽 위 메뉴 → **SMTP & API → API Keys → Generate a new API key** → 키(`xkeysib-...`)를 복사해 둡니다.
> 개인 메일(gmail 등)로 보내면 받는 사람의 스팸함에 들어갈 수 있어요. 처음 안내할 때 "스팸함도 확인해 주세요"라고 알려 주세요.

### 3단계. (선택) GitHub 토큰 — AI 상담사용
1. https://github.com/settings/personal-access-tokens/new 접속
2. 이름 `maum-ai`, 만료일 선택 → **Permissions → Account permissions → Models → Read-only**
3. **Generate token** → 토큰(`github_pat_...`)을 복사해 둡니다.
> 건너뛰면 AI 상담사가 내장 공감 응답으로 대답합니다.

### 4단계. Render — 서버 올리기 (약 5분)
1. https://render.com 접속 → **Get Started** → GitHub 계정으로 가입
2. **New + → Blueprint** → GitHub 저장소 목록에서 **maum** 선택 (안 보이면 *Configure GitHub* 로 저장소 접근 허용)
3. 입력 칸이 나오면 아래처럼 채웁니다.
   | 항목 | 넣을 값 |
   |---|---|
   | ADMIN_EMAIL | 관리자로 쓸 내 메일 |
   | ADMIN_PHONE | 관리자로 쓸 내 휴대전화 번호 |
   | TURSO_DATABASE_URL | 1단계의 Database URL |
   | TURSO_AUTH_TOKEN | 1단계의 토큰 |
   | BREVO_API_KEY | 2단계의 API 키 |
   | MAIL_FROM_EMAIL | 2단계에서 인증한 보내는 메일 |
   | GITHUB_MODELS_TOKEN | 3단계 토큰 (안 했으면 비워 두기) |
4. **Apply** → 3~5분 기다리면 `https://maum-xxxx.onrender.com` 주소가 생깁니다.
5. 그 주소로 들어가 **ADMIN_EMAIL / ADMIN_PHONE** 으로 로그인 → 메일로 온 인증번호 입력 → 관리 콘솔
6. 관리 콘솔 → **상담사 관리**에서 상담 선생님 계정을 추가하고, 주소를 학생·선생님들에게 공유하세요.

### 꼭 지켜 주세요
- Render의 **Environment** 화면에 있는 `DATA_KEY` 값을 복사해 안전한 곳에 보관하세요. 이 키가 바뀌거나 없어지면 저장된 상담 내용을 읽을 수 없습니다.
- 관리 콘솔 첫 화면에 빨간 "임시 상태" 안내가 보이면 Turso 설정이 빠진 것입니다. 노란 "시험 모드" 안내가 보이면 Brevo 설정이 빠진 것입니다(이때는 인증번호가 화면에 그대로 보여 보안에 취약합니다).
- 무료 서버는 잠들 수 있어 **24시간 위기 대응을 보장하지 않습니다.** 위기 알림 메일(ALERT_EMAILS)을 받을 담당자와 대응 절차를 꼭 정해 두세요.
- 코드를 고친 뒤 GitHub에 올리면(push) Render가 자동으로 다시 배포합니다.

## 내 컴퓨터에서 실행하기
```bash
# Node.js 22 이상 필요 (데이터는 data/ 폴더에 저장, 별도 DB 설치 불필요)
npm install
cp .env.example .env      # 필요 시 수정
npm run seed              # (선택) 데모 내담자·검사·알림 데이터
npm start                 # → http://localhost:3000
```
데모 계정 (메일 / 연락처) — 개발 모드에서는 인증번호가 화면에 바로 표시됩니다.

|---|---|---|
| 관리자 | admin@maeumgyeol.local | 010-0000-0000 |
| 상담사 | counselor@maeumgyeol.local | 010-1111-2222 |
| 내담자(고위험 예시) | seojun@demo.kr | 010-2000-0001 |

## 주요 기능
**내담자**
- 로그인: 메일 주소 + 휴대전화 번호 → 메일로 받은 6자리 인증번호 입력 (10분 유효, 5회 제한)
- 가입: 대상(초/중/고/성인/교사 — 교사는 인증코드 필요, 기본값 `maum2026`, .env의 `TEACHER_CODE`로 변경), 필수 동의(개인정보·민감정보·비밀보장 예외), 만 14세 미만 보호자 정보·동의
- 심리검사 11종 (대상별로 자동 노출): PHQ-9(우울), GAD-7(불안), K-6(심리적 고통·무력감), 스마트폰 과의존(NIA), 게임 과몰입(IGDS9-SF), 도박 문제(PGSI), AI 의존 자가점검, 고립감·은둔(UCLA-3+보조), 자존감(RSES), 안전 확인(C-SSRS 선별), 어린이용 마음 날씨
- 결과 즉시 확인 + 메일 자동 발송(설정에서 끄기 가능) + 다시 메일 받기
- 그림 치료 11과제: 지금 내 마음, 감정 색, 집·나무·사람(HTP), 빗속의 사람, 동적 가족화, 화면 안/밖의 나, 풍경 구성, 만다라, 세상 밖으로 나온 나
  - 연필·붓(필압)·크레파스·형광펜·채우기·지우개, 24색+직접 선택, 되돌리기/다시, 터치 지원
  - 기기에 PNG 저장 · 임시 저장 · 사후질문(PDI) 후 상담사에게 전송 · 메일로 받기
  - 그리기 과정 지표(소요 시간, 지우기 횟수, 화면 사용, 위치, 색 분포)로 규칙 기반 해석 → 상담사가 답장 작성
- 채팅 상담(실시간) + **AI 상담사**: 상담 선생님이 연결되기 전까지 AI가 즉시 공감·응대하고, 위기 표현이 나오면 안전 확인과 109 안내를 먼저 함. 상담 선생님이 상담을 맡으면 AI는 자동으로 물러나며, 선생님이 필요할 때 다시 켤 수 있음
  - Codespaces에서는 자동 제공되는 GitHub 토큰으로 GitHub Models(무료)를 사용, 연결이 안 되면 내장 공감 응답으로 대답
- 기분 기록, 쉼터(호흡·세상 밖으로 작은 걸음 미션·디지털 쉼표), 안전계획(Stanley-Brown 형식)
- 어디서나 보이는 **SOS 버튼**: 109·1388·1577-0199·119/112 바로 걸기, 상담사에게 알리기

**위기 감지 → SOS → 관리자 모니터링**
| 신호 | 단계 |
|---|---|
| PHQ-9 9번 문항 양성, 어린이 10번 문항 양성 | 위험~긴급 (+ 안전 확인 문항 자동 권유) |
| C-SSRS 의도·계획·최근 시도 | 긴급 |
| PHQ-9 ≥15, K-6 ≥13, PGSI ≥8 | 위험 |
| 채팅·기분 메모·그림 사후질문의 위기 표현 | 관심/위험/긴급 |
| 내담자의 SOS 버튼 | 긴급 |
위험·긴급 단계: 내담자에게 SOS 창 → 관리자 콘솔 실시간 알림(소리·브라우저 알림) → 관리자 메일 발송.

**관리자·상담사 콘솔** — 한눈에 보기, 위기 알림 처리(확인/해결+조치 메모), 내담자별 상태 요약·참고 소견(선별 기반, 진단 아님)·권고 조치, 검사 이력, 그림 해석, 채팅 상담 배정, 상담자 메모, 상담사 관리, 열람 기록, 보낸 메일.

## 비밀보장 설계
- 채팅·기분 메모·안전계획·사후질문·상담자 메모·그림 파일은 **AES-256-GCM 암호화** 저장
- 채팅 내용은 내담자와 **배정된 상담사만** 열람 가능
- **긴급 열람(break-glass)**: 관리자만, 위험·긴급 알림이 진행 중일 때만, 사유 입력 필수, 30분 유효, 모든 열람이 감사 로그에 기록
- 상담자 해석 메모는 "공개" 체크 시에만 내담자에게 보임

## 운영 전 꼭 확인하세요
1. **SMTP 설정**(.env): 설정 전에는 메일이 실제로 나가지 않고 '보낸 메일'에만 저장됩니다. Gmail은 앱 비밀번호 사용.
2. **DATA_KEY**를 지정하고 안전하게 백업하세요. 잃어버리면 상담 기록을 복호화할 수 없습니다.
3. `NODE_ENV=production` + HTTPS(리버스 프록시) 환경에서 운영하세요.
4. **위기 대응 프로토콜**(누가, 몇 분 안에, 어떻게 연락하고 어디로 연계하는지)과 상담사 근무 시간을 기관 차원에서 정하세요. 키워드 기반 감지는 놓치거나 오탐할 수 있으므로 사람의 판단을 대신하지 않습니다.
5. 개인정보보호법상 민감정보 처리, 14세 미만 법정대리인 동의, 개인정보 처리방침 게시 등 법적 요건을 기관 담당자와 확인하세요.
6. 검사 도구 중 'AI 의존 자가점검', '마음 날씨 체크'는 비표준화 참고용 문항입니다. 표준화 도구도 진단이 아닌 선별 목적입니다.
7. (선택) `ANTHROPIC_API_KEY`를 넣으면 그림 AI 해석 보조와 내담자 상태 AI 요약이 켜집니다.
